# Natural Beauty Spot — multi-page website

Open `index.html` in a browser. All eight pages load `config.js` followed by `script.js`.

## Pages

Home, About, Services, Gallery, Before / After, Behind the Scenes, Reviews, Contact.

## Update everything in one place

Edit `config.js` for business name, artist name, phone, WhatsApp number, Instagram, social URLs, descriptions, service cards, gallery images, comparisons, BTS entries and the reviews array. The same data powers every page.

## Images

- `assets/images/logo/` — replaceable brand logo
- `assets/images/services/` — haircut & styling, color & treatments, skin & makeup, bridal makeup
- `assets/images/before-after/` — two sample pairs
- `assets/images/behind-scenes/` — makeup preparation, hairstyling, finishing touches
- `assets/images/hero.svg` — hero background

All bundled images are **SVG illustrations and placeholders**, not photos of the artist or genuine client results. Replace with authorized real photos before publishing. Update paths in config.js.

## Review carousel

Slides move continuously left, loop automatically, pause on hover/focus and can be moved with Previous/Next buttons or touch swipes. Review content comes from `config.js`. Sample reviews must be replaced with genuine testimonials before launch.

## Booking

The form prepares a WhatsApp message for +91 9699154154. It does not save, send automatically or confirm an appointment. No backend is required.

## Testing

Run through each page and test links, carousel, mobile navigation and WhatsApp on target browsers before publishing. Fonts use Google Fonts and require internet.
